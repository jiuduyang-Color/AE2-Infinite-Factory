# AE2 Infinite Factory 整合包存档

本仓库用于存档与分享 **AE2 Infinite Factory** 整合包的多个版本，方便朋友直接下载。

- CurseForge 项目页：https://www.curseforge.com/minecraft/modpacks/ae2-infinite-factory

## 下载

整合包体积较大，统一放在 [Releases](../../releases) 页面，点击对应版本附件即可下载：

| 版本 | 文件 | 大小 |
| --- | --- | --- |
| 1.x | `AE2 Infinite Factory.zip` | 约 44 MB |
| 2.0.0 | `AE2 Infinite Factory-2.0.0.zip` | 约 181 MB |
| 3.0.0 | `AE2 Infinite Factory-3.0.0.zip` | 约 573 MB |

## 安装

1. 安装对应版本的 Minecraft 与整合包启动器（推荐 CurseForge App 或 Prism / HMCL）。
2. 下载 zip 后，直接导入启动器（或解压到 `instances` 目录）。
3. 首次启动前请给游戏分配足够的内存（3.0.0 建议 6 GB 以上）。
